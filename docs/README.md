# Geometric Lib

Библиотека для вычисления площади и периметра геометрических фигур: круга, квадрата, прямоугольника и треугольника.

## Функции

### Круг — `circle.py`

- `area(r)` — площадь круга, где `r` — радиус. Возвращает `float`.
- `perimeter(r)` — длина окружности, где `r` — радиус. Возвращает `float`.

```python
import circle

print(circle.area(7))
print(circle.perimeter(8))
```

### Квадрат — `square.py`

- `area(a)` — площадь квадрата, где `a` — сторона. Возвращает `int`.
- `perimeter(a)` — периметр квадрата, где `a` — сторона. Возвращает `int`.

```python
import square

print(square.area(6))
print(square.perimeter(9))
```

### Прямоугольник — `rectangle.py`

- `area(a, b)` — площадь прямоугольника, где `a` и `b` — стороны. Возвращает `int`.
- `perimeter(a, b)` — периметр прямоугольника по формуле `2 * (a + b)`. Возвращает `int`.

```python
import rectangle

print(rectangle.area(4, 12))
print(rectangle.perimeter(7, 11))
```

### Треугольник — `triangle.py`

- `area(a, h)` — площадь треугольника, где `a` — основание, `h` — высота. Возвращает `float`.
- `perimeter(a, b, c)` — периметр треугольника. Возвращает `int`.
  - `a` — сторона треугольника.
  - `b` — сторона треугольника.
  - `c` — сторона треугольника.

```python
import triangle

print(triangle.area(8, 14))
print(triangle.perimeter(6, 8, 10))
```
