# Проект для вычисления геометрических величин

## Общее описание

Проект предназначен для вычисления площади и периметра квадрата, прямоугольника и треугольника, а также площади и длины окружности круга.

## Описание функций

### `circle.area(r)`

Вычисляет площадь круга.

- Принимает: `r` (`int`)
- Возвращает: `float`

Пример:

```python
print(area(7))
```

### `circle.perimeter(r)`

Вычисляет длину окружности.

- Принимает: `r` (`int`)
- Возвращает: `float`

Пример:

```python
print(perimeter(8))
```

### `square.area(a)`

Вычисляет площадь квадрата.

- Принимает: `a` (`int`)
- Возвращает: `int`

Пример:

```python
print(area(6))
```

### `square.perimeter(a)`

Вычисляет периметр квадрата.

- Принимает: `a` (`int`)
- Возвращает: `int`

Пример:

```python
print(perimeter(9))
```

### `rectangle.area(a, b)`

Вычисляет площадь прямоугольника.

- Принимает: `a`, `b` (`int`)
- Возвращает: `int`

Пример:

```python
print(area(4, 12))
```

### `rectangle.perimeter(a, b)`

Вычисляет периметр прямоугольника.

- Принимает: `a`, `b` (`int`)
- Возвращает: `int`

Пример:

```python
print(perimeter(7, 11))
```

### `triangle.area(a, h)`

Вычисляет площадь треугольника.

- Принимает: `a`, `h` (`int`)
- Возвращает: `float`

Пример:

```python
print(area(8, 14))
```

### `triangle.perimeter(a, b, c)`

Вычисляет периметр треугольника.

- Принимает: `a`, `b`, `c` (`int`)
- Возвращает: `int`

Пример:

```python
print(perimeter(6, 8, 10))
```
